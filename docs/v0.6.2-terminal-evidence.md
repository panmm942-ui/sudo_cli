# v0.6.2 terminal acceptance

The final acceptance passed on 8 October 2026 in four real Linux x64 terminals.
The processes ran as root in WSL, with private project, HOME, XDG, state and
temporary directories. They used the pinned native Codex engine and the actual
SUDO CLI input, provider bridge, sandbox and chat persistence.

The model endpoint was a deterministic loopback streaming fixture. No paid AI,
real model weights, runner installation, physical microphone or desktop app was
used in this acceptance.

The final run made **3 native model requests**: literal paste, the multi-line

The exhaustive inventory pass was enabled. The retained sanitized receipt lists
all 59 selected command names, rather than assuming a fixed number of commands.

## Reproduce

Run from the product directory with the pinned Linux runtime installed:

```sh
sudo python3 -B test/manual/verify-v0.6.2-linux.py \
  --output-directory /tmp/sudocli-v062-proof
```

The directory contains a JSON receipt, sanitized terminal transcripts, raw ANSI
transcripts and the fixture's provider requests. `--skip-inventory` is only a
diagnostic option; it does not perform the complete registry selection pass.

This Linux PTY run does not establish physical Windows or macOS terminal
behavior. A synthetic GGUF header demonstrates inspection and extension-independent
content detection; it does not demonstrate real model loading or inference.
